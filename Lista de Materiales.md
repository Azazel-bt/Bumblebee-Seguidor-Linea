## 🛒 Lista de Materiales (BOM)

A continuación se detallan los componentes de hardware y elementos electrónicos utilizados para la construcción del robot:

### 🧠 Control y Lógica
| Componente | Descripción | Cantidad |
| :--- | :--- | :---: |
| **Placa de Desarrollo Arduino Uno** | Microcontrolador principal encargado del procesamiento de señales y lógica de control. | 1 |
| **Módulo LCD 16x2 con Adaptador $I^2C$ (PCF8574)** | Pantalla para la interfaz visual y renderizado de las animaciones de los ojos. | 1 |

### ⚡ Actuación y Potencia
| Componente | Descripción | Cantidad |
| :--- | :--- | :---: |
| **Módulo Driver Motor H-Bridge L298N** | Controlador de potencia para el manejo de los dos motores DC independientes mediante PWM. | 1 |
| **Motoreductores DC (Amarillos) con Ruedas** | Actuadores para la tracción diferencial del chasis (Relación recomendada 48:1 o 120:1). | 2 |
| **Rueda Loca (Caster Wheel)** | Soporte omnidireccional delantero para el balance del chasis. | 1 |

### 👁️ Sensado y Alimentación
| Componente | Descripción | Cantidad |
| :--- | :--- | :---: |
| **Sensores Infrarrojos TCRT5000** | Módulos seguidores de línea (Salida digital DO conectada a pines 4 y 2). | 2 |
| **Batería Recargable  9V** | Fuente de alimentación principal . | 1 |

### 🔧 Elementos de Conexión y Chasis
| Componente | Descripción | Cantidad |
| :--- | :--- | :---: |
| **Chasis de Acrílico de 2 Ruedas 3D / Carton** | Estructura base para el montaje de motores, sensores y placas. | 1 |
| **Cables de Conexión (Jumpers)** | Cables DuPont (Macho-Macho, Macho-Hembra, Hembra-Hembra). | 1 Pack |
| **Interruptor On/Off (Switch)** | Switch de palanca o botón para el encendido general del sistema. | 1 |
